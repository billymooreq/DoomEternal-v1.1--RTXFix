# DoomEternal-v1.1--RTXFix — исправление освещения окружения в DOOM Eternal 1.1 на NVIDIA

[English](README.md) | **Русский**

На современных драйверах NVIDIA DOOM Eternal **1.1** рисует затенённые части оружия от первого лица полностью чёрными,
а в мире пропадают локальные источники света, декали и объёмный свет. doomfix — небольшой Vulkan-слой, который это
исправляет **без отката драйвера на 516.94**, а на RTX 40 и RTX 50 такой откат и вовсе невозможен.

## Это безопасно?

- Это **Vulkan-слой**: дополнение того же рода, что используют ReShade, MSI Afterburner / RivaTuner и оверлей Steam.
  Windows подгружает его в игру при запуске.
- **Файлы игры не меняются.** В папке игры ничего не трогается.
- **Геймплей и тайминги не затрагиваются.** Слой добавляет один флаг синхронизации в три барьера GPU в коде
  освещения игры, ровно как это сделали сами id Software в поздних патчах. Всё остальное проходит без изменений.
- **Открытый исходный код** (лицензия MIT): можно прочитать каждую строку и собрать самому.
- **Никакого сбора данных:** doomfix не обращается к сети. Подробности: [PRIVACY.md](PRIVACY.md) (на английском).
- **Легко удалить:** «Параметры → Приложения» (или `uninstall.bat` для zip) убирает его полностью.

## Совместимость

| | |
|---|---|
| **Проверено** | GeForce RTX 4070, драйвер NVIDIA 617.42, DOOM Eternal 1.1 (Steam) |
| **Должно работать** | на любой видеокарте NVIDIA с новым драйвером, где есть баг с чёрным оружием |
| **AMD** | на AMD этой проблемы нет; слой там ничего не ломает |
| **ОС** | только Windows (64-бит) |

Попробовали на другой видеокарте или драйвере? Пожалуйста, напишите о результате, удачном или нет, в [Issues](../../issues):
видеокарта, версия драйвера, версия игры и выглядит ли оружие правильно.

## Установка

Откройте [Releases](../../releases) и выберите один из двух файлов в списке *Assets* самого нового релиза.
Оба устанавливают один и тот же слой для вашего пользователя Windows; права администратора не нужны.

**Установщик (рекомендуется): `doomfix-<версия>-setup.exe`**

1. Запустите его. Он найдёт DOOM Eternal в вашей библиотеке Steam (или нажмите «Обзор» и выберите папку,
   где лежит `DOOMEternalx64vk.exe`).
2. Выберите, нужен ли ярлык на рабочем столе (ярлык в меню «Пуск» создаётся всегда).
3. Запускайте игру ярлыком **DOOM Eternal (doomfix)** (на рабочем столе или в меню «Пуск»).

Установщик пока не подписан (см. [политику подписи кода](docs/CODE_SIGNING_POLICY.md), на английском), поэтому Windows
может показать «Система Windows защитила ваш компьютер»: нажмите «Подробнее», затем «Выполнить в любом случае».

**Zip, без exe-установщика: `doomfix-<версия>.zip`**

1. Распакуйте его в любое место, например в `Документы\doomfix`. Эту папку не удаляйте: в ней лежат лаунчер и деинсталлятор.
2. Запустите `install.bat`.
3. Запускайте игру через `run_doom_fixed.bat` (см. [Использование](#использование)).

Уже ставили doomfix через `install.bat` и хотите перейти на установщик? Просто запустите его: он заменит старую
установку на месте, а старую папку doomfix после этого можно удалить.

**Обновление с 0.3.1:** необязательного *режима Steam* (`enable_steam_mode.bat`) больше нет, см.
[Кнопка «Играть» в Steam](#кнопка-играть-в-steam). Если он был включён, установщик и `install.bat` выключат его и
сообщат об этом; после этого перезапустите Steam.

Каждый релиз собирается из этого исходного кода в GitHub Actions, а в его описании указан SHA256 обоих файлов.
Релизы с пометкой *Pre-release* — тестовые сборки. Собрать doomfix самостоятельно можно по [docs/BUILDING.md](docs/BUILDING.md)
(на английском).

## Использование

### Запуск игры

**Установщик:** дважды щёлкните ярлык **DOOM Eternal (doomfix)**. Это всё. Steam должен быть запущен.
Если папка игры изменится, ярлык спросит новую.

**Zip:** дважды щёлкните **`run_doom_fixed.bat`**. При первом запуске он найдёт DOOM Eternal в вашей библиотеке Steam
и попросит подтвердить папку (или ввести путь, если игра установлена в другом месте). Папка запоминается, и дальше
игра просто запускается. Steam должен быть запущен.

### Кнопка «Играть» в Steam

Кнопка «Играть» в Steam запускает игру **без** исправления. doomfix включается только для игры, запущенной ярлыком
doomfix или через `run_doom_fixed.bat`, и никогда для других программ. Сам Steam при этом должен быть запущен.

В версии 0.3.1 был необязательный *режим Steam*, который включал слой во всех Vulkan-играх, запущенных из Steam.
Он убран: под него попадали и онлайн-игры с античитом, а это лишний риск.

### Как проверить, что всё работает

При каждом запуске игры пишется лог `%LOCALAPPDATA%\doomfix\logs\DOOMEternalx64vk_<дата-время>_<pid>.log`.
Когда вы окажетесь на уровне, в нём должны быть такие строки:

```
INFO  doomfix 0.3.1 (VK_LAYER_DOOMFIX) loaded into <папка игры>\DOOMEternalx64vk.exe, pid 1234
INFO  indirect-barrier-fix [on]: PATCHED vkCmdPipelineBarrier in command buffer 000002CD804070D0
INFO  indirect-barrier-fix [on]: barriers with DRAW_INDIRECT dst 1800 (+1800), patched 1800 (+1800), ...
```

Последняя строка повторяется каждые несколько секунд, пока вы играете, и числа в ней растут.

### Режимы

У фикса четыре режима, их выбирает переменная `DOOMFIX_INDIRECT_FIX`. В zip для каждого режима есть свой лаунчер;
при установке установщиком запускайте `%LOCALAPPDATA%\doomfix\doomfix_launcher.exe --mode <режим>` (например, из копии
ярлыка, дописав к его объекту `--mode strict`).

| Режим | Лаунчер | Что делает |
|---|---|---|
| `on` (по умолчанию) | `run_doom_fixed.bat` | Фикс, ровно такой же, как сделали id Software в поздних патчах. Используйте этот. |
| `strict` | `run_fix_strict.bat` | `on` плюс одно дополнительное ожидание для надёжности (так работал `on` в v0.2). Попробуйте, если в `on` когда-нибудь появится мерцание или пропадут источники света. |
| `off` | `run_fix_off.bat` | Слой загружен, но ничего не меняет — чтобы сравнить «до» и «после». |
| `aggressive` | `run_fix_aggressive.bat` | Использует более тяжёлые барьеры «дождаться всего». Запасной вариант на случай, если `on` когда-нибудь окажется недостаточно; обычно не нужен. |

## Удаление

- **Установщик:** «Параметры → Приложения → Установленные приложения → doomfix → Удалить».
- **Zip:** запустите `uninstall.bat`, затем удалите папку doomfix.

Оба способа убирают слой и его записи в реестре. Логи остаются: если они не нужны, удалите потом
`%LOCALAPPDATA%\doomfix`.

## Решение проблем

**Фикс не работает: оружие всё ещё чёрное.**
Убедитесь, что игра запущена ярлыком doomfix или через `run_doom_fixed.bat`, а не кнопкой «Играть» в Steam, и что
ничего из этого не запущено **от имени администратора**: ни игра, ни ярлык, ни `run_doom_fixed.bat`.
Windows не загружает doomfix в программы, запущенные от имени администратора, и игра тогда работает без фикса.
Проверьте также вкладку *Совместимость* в свойствах `DOOMEternalx64vk.exe`: галочка
*Запускать эту программу от имени администратора* должна быть снята. Ярлык doomfix и установщик предупреждают об этом.

**Игра запускается, но оружие всё ещё чёрное и нового лога нет.**
DOOM Eternal может перезапустить себя через Steam, и перезапущенная игра уже не получает переменные doomfix.
Ярлык doomfix и `run_doom_fixed.bat` предотвращают это, задавая `SteamAppId=782330`; убедитесь, что Steam запущен,
прежде чем ими пользоваться.

**Установщик или `install.bat` предупреждает о другом файле настроек loader'а.**
Этот файл создаёт Vulkan Configurator (vkconfig) из состава Vulkan SDK. Загрузчик Vulkan использует только один такой
файл, поэтому doomfix его не перезаписывает. Закройте vkconfig или выключите в нём «Vulkan Loader Management» и
запустите установщик (или `install.bat`) ещё раз.

**Антивирус или SmartScreen ругается на doomfix.**
Файлы пока не подписаны цифровой подписью, а DLL подгружается в игру так же, как оверлей, и некоторым антивирусам это
не нравится. У каждого релиза есть контрольные суммы SHA256 и build provenance attestation, по которым можно
проверить, что файлы собраны из этого репозитория.
Исходный код открыт: можно собрать DLL самому ([docs/BUILDING.md](docs/BUILDING.md)) и/или добавить исключение для папки
doomfix и для `%LOCALAPPDATA%\doomfix\layer`.

**Лога нет совсем.**
Проверьте, что установщик или `install.bat` завершился без ошибок и что игра запущена с `DOOMFIX_ENABLE=1` (ярлыком
doomfix или через `run_doom_fixed.bat`). `run_doom_fixed.bat -DryRun` проверяет установку и папку игры, не запуская игру.

## Как это работает

Каждый кадр DOOM Eternal раскладывает источники света, декали и пробы отражений по трёхмерной сетке маленьких
«кластеров» прямо на видеокарте. Это происходит в два шага: первый шаг записывает, сколько работы предстоит второму,
а второй шаг читает эти числа. Перед чтением игра должна сказать видеокарте, чтобы та сделала свежезаписанные числа
видимыми, а версия 1.1 забывает для этого один флаг (`VK_ACCESS_INDIRECT_COMMAND_READ_BIT`) в трёх местах.
Видеокарты AMD всё равно видят правильные числа; современные драйверы NVIDIA читают устаревшие нули, поэтому в каждом
кластере остаётся только солнце, и оружие в тени не получает света совсем. doomfix добавляет недостающий флаг, пока игра
записывает свои команды для видеокарты, — то же изменение, которое id Software сделали в поздних обновлениях.

Подробнее: [docs/TECHNICAL.md](docs/TECHNICAL.md) (на английском). Полное расследование с захватами RenderDoc и
сравнением с актуальной версией игры: [analysis/report.md](analysis/report.md).
